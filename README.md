Entry for the [make.fun bounty "The One-Sentence Apology Your Agent Owes You"](https://make.fun/bounty/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0) — one sentence of apology an AI assistant owes the person it works for: funny and human at once, a real comic turn about a real failure, at most 200 characters.

## Run

```sh
python3 main.py
```

Writes the apology to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no dependencies, deterministic.
